# 冰箱管家 · 设计定稿（v0.2）

设计稿与可点击原型：https://claude.ai/code/artifact/d61c7264-b89c-4571-8377-411e2b64125e
定稿日期：2026-10-11。实现原则：怎么简单怎么来，不符合 MVP 的以后再改。

## 视觉
- 风格：粉彩 + 手绘线条（参考手绘图标风格），奶油底、深可可色描边。
- 颜色：奶油底 #FBF6EC｜卡片纸 #FFFDF8｜墨线 / tint #3A2E28｜可可灰（次要文字）#76675C｜蜂蜜黄（主按钮）#F4C95D
- 过期状态：已过期 #EE8C7E｜快过期（0–2 天）#F9C79A + 闹钟图标｜正常：不上色，灰描边｜冷冻 #C7DDF0 + 雪花图标。每种状态都配文字（已过期 N 天 / 今天过期 / 明天过期 / 剩 N 天 / 冷冻）。
- 分类底色：肉类 #F6CFCB｜半成品 #F7E6B0｜蔬菜 #D3E8CB｜蛋奶 #E2D8F0
- 字体：标题用站酷快乐体（ZCOOL KuaiLe，只用在标题上，打包一个字体文件）；其余用系统字体。
- 图标：12 个手绘 SVG，放进 Asset Catalog。Tab 选中态用填了蜂蜜黄的那一版图标。
- 形状：统一圆角 + 描边（RoundedRectangle().stroke）。卡片圆角 18、2pt 描边；主按钮圆角 16，带 3pt 硬投影。
- 原生组件：TabView、NavigationStack、Sheet、Form、Segmented Picker、Stepper、Menu Picker。

## 交互定稿
- 冰箱页：顶部「尽快用掉」分组（冷藏且 ≤2 天，含已过期），下面按分类分组，组内按剩余天数排序、冷冻排最后。每个食材一张独立卡片（List 行背景），左滑删除。支持全部/冷藏/冷冻切换和搜索。
- 添加/编辑：分类和位置用分段选择，数量用步进器（步长 0.5），单位用下拉菜单。过期日按分类默认天数计算（肉类 3、半成品 5、蔬菜 5、蛋奶 7），可以手动改、可以恢复默认。冷冻时隐藏过期日；冷冻改冷藏时，过期日从当天重新算。添加日期可改。添加模式有「保存并继续添加」，编辑模式底部有删除（带确认）。
- 做饭页：菜系选中餐/西餐；人数用步进器，1–10 人（建议记住上次的选择）。下方列出快过期食材，只展示、不勾选，生成时作为「优先用掉」传给 AI；已过期的不参与推荐。未设置 API Key 时显示提示卡片，按钮置灰。
- 推荐结果：生成中显示骨架卡片；出 2–3 个方案，按用到的快过期食材数量排序，标出用到了哪些快过期食材。右上角可重新生成。错误分两种：网络失败、AI 返回异常。切走再回来保留上次结果。
- 方案详情：分菜展示，每道菜列出冰箱里的食材和用量、「需另备」的调料（默认调料家里都有），以及步骤。底部是「做完了」。
- 确认扣减（Sheet）：每项可以取消勾选、调整用量，剩余 ≤0 时标「将移除」。确认后回到冰箱页并提示。
- 设置：API Key 用安全输入框，可显示/隐藏；模型 ID 输入框下面有常用模型快捷选项；有「测试连接」按钮；最后是关于和版本号。没有默认设置。
